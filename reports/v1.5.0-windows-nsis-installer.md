## 🎯 Executive Summary
Version 1.5.0 packages the Playwright Embedded Desktop Studio into a full-featured, standard **Windows Setup Installer (`.exe`)** utilizing the NSIS packaging system.

This enables end-users and non-technical testers to easily install, configure installation directories, create Start Menu and Desktop shortcuts, and manage uninstallation through Windows Settings / Control Panel.

---

## 🚀 Installer Features & Configuration

### 1. NSIS Wizard Configuration
- **Customizable Install Directory**: Allows testers to install to the default location (`%LOCALAPPDATA%\Programs\Playwright Embedded Studio`) or choose a custom drive/folder.
- **Shortcuts**: Automatically creates:
  - Desktop Shortcut (`Playwright Embedded Studio.lnk`).
  - Start Menu Folder and Application shortcut.
- **Clean Uninstallation**: Creates `Playwright Embedded Studio-Setup-1.0.0.__uninstaller.exe` and registers the app in Windows `Add or Remove Programs` for clean removal.
- **AppData Preservation**: `deleteAppDataOnUninstall: false` preserves test workspaces, custom templates, and reports during app upgrades.

### 2. Binary Details & Compression
- **Installer File**: `dist-release/Playwright Embedded Studio-Setup-1.0.0.exe`
- **File Size**: ~85.3 MB (compressed via 7-Zip NSIS solid compression).
- **Blockmap**: `Playwright Embedded Studio-Setup-1.0.0.exe.blockmap` generated for delta updates.
- **Portable Unpacked**: Still preserved in `dist-release/win-unpacked/` for instant execution without installation.

### 3. Security & Code Signing
- Signed with Authenticode SHA-256 certificate `B4127AF640CE91901058744ECDC3AE9718BE4482`.
- SmartScreen unblocked using PowerShell `Unblock-File`.
