**Release Date:** 2026-09-08  
**Artifact Target:** Portable Unpacked (`dist-release/win-unpacked/Playwright Embedded Studio.exe`)  
**Status:** ✅ Production Ready & Code Signed

---

## 🎯 Executive Summary
Version 1.3.0 introduces a modern **Searchable Combobox & Dropdown Suggestion System** in the `Scenario & Tests` studio. This feature replaces native HTML `<datalist>` elements with a fully interactive, searchable popup dropdown that allows both click-to-select and manual typing.

Testers can now easily pick from all available pages in the bound Locator Repository, and then view and select from all element keys belonging to the selected page, complete with live selector expression previews (e.g. `#login-button`, `[data-test="error"]`).

---

## 🚀 Key Enhancements

### 1. New Component: `SearchableCombobox.tsx`
- **Hybrid Input & Dropdown**:
  - Acts as a normal text input allowing free manual typing (supports dynamic tokens like `{{ROW_INDEX}}`, custom locators, or arbitrary element names).
  - Contains a right-docked chevron toggle button that opens/closes the suggestions dropdown anytime.
  - Automatically opens suggestions on input focus or click.
- **Smart Real-Time Search & Switch**:
  - Filters suggestions instantly as the user types (matches element key, label, or selector expression).
  - If the typed value is an exact match for an existing option, opening the dropdown shows all available options so the user can seamlessly switch to any other element on the page.
- **Keyboard Navigation Support**:
  - `ArrowDown` / `ArrowUp` to navigate options.
  - `Enter` to confirm and select highlighted option.
  - `Escape` / `Tab` to dismiss dropdown.
- **Flawless Event Handling**:
  - Uses `onMouseDown={(e) => e.preventDefault()}` on the dropdown popover and toggle button to prevent focus loss and eliminate spurious blur/refocus loops.
  - Automatically scrolls the highlighted item into view.
  - Smooth animation with `backdrop-blur-md`, dark palette styling, and high z-index stacking (`z-50`).

---

### 2. Rich Locator Metadata Extraction (`ScenarioEditor.tsx` & `ScenarioStudio.tsx`)
- Updated `scopedLocatorMap` to preserve element selector expressions and locator types:
  - Stored as `LocatorItemMeta { name: string; selector?: string; type?: string }`.
  - Parses both nested Page Object dictionaries (`{ LoginPage: { usernameInput: "#user-name" } }`) and flat element repositories.
  - Passes rich locator metadata down to `StepItem` for real-time previewing.

---

### 3. Smart Suggestions in `StepItem.tsx`
- **Page Object Combobox**:
  - Dropdown displays all pages defined in the bound repository.
  - Displays element counts per page (e.g. `LoginPage` • `4 elements`).
- **Element Key Combobox**:
  - When a page is selected, clicking or typing in `Element Key` reveals all elements belonging to that page.
  - Each item displays:
    - **Element Key** in bold teal / emerald text (`usernameInput`, `loginBtn`).
    - **Selector Expression** in monospace slate text (`#user-name`, `[data-test="error"]`).
    - **Locator Type Badge** (`css`, `xpath`) when present.
    - Checkmark indicator on the currently selected element.
  - If no page has been selected yet, displays helpful guidance: `(Select page for suggestions)` while still allowing manual typing.
  - If no repository has been bound, maintains strict security: locks inputs with amber badge `(Repo required)` and placeholder `⚠️ Bind Locator Repo above first`.
